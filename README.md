# CR7 Legacy | Trayectoria & Academia Deportiva ⚽👑

[![Estado del Proyecto](https://img.shields.io/badge/Status-Completado-brightgreen)](https://github.com/)
[![Design](https://img.shields.io/badge/UI%20Style-Premium%20Dark%20%26%20Gold-amber)](https://github.com/)

**CR7 Legacy** es un sitio web tributo y conceptual dedicado a la legendaria carrera de Cristiano Ronaldo, integrando un enfoque de academia de alto rendimiento técnico. Desarrollado con fines académicos para la **Universidad Tecnológica del Perú (UTP)**, el proyecto destaca por una interfaz de usuario limpia, un contraste de alto impacto visual (Dark con acentos dorados) y una maquetación moderna.

---

## 🎯 Enfoque Técnico & Maquetación
El principal objetivo de este repositorio es demostrar destreza en el diseño de interfaces (UI) y consistencia en el desarrollo estructural mediante:
* **Semántica de Alto Nivel:** Maquetación estructurada con HTML5, asegurando que cada sección (Academia, Trayectoria, Comunidad) sea independiente y accesible.
* **Diseño Visual de Impacto:** Uso de CSS3 para lograr una estética deportiva premium, tipografías imponentes y distribución limpia de elementos gráficos.
* **Secciones Modulares:** Organización clara de rutas para ofrecer una navegación fluida entre las diferentes páginas del proyecto.

---

## 💻 Secciones Implementadas
* **Landing Page Principal:** Hero section con diseño asimétrico impactante y llamadas a la acción claras ("Ver Más").
* **Módulo de Academia:** Sección informativa con estadísticas clave de formación (Alumnos, Entrenadores, Títulos).
* **Trayectoria & Momentos Destacados:** Línea de tiempo conceptual de los hitos de su carrera.
* **Comunidad & Productos:** Vistas orientadas a la fidelización de usuarios y catálogo visual de indumentaria.

---

## 🛠️ Stack Tecnológico
* **HTML5** - Estructuración del contenido, uso de contenedores semánticos y optimización de jerarquía de textos.
* **CSS3** - Paleta de colores personalizada (Blanco, Negro profundo y Amarillo/Oro), alineación mediante Flexbox y Grid Layout.
